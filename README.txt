COMO CORRER EL PROYECTO
------------------------
leer requirements.txt e instalar todo lo que sea necesario
Estando dentro de la carpeta del proyecto, ejecutar en orden:

    docker compose up -d

    make run

Eso es todo. El sistema levanta RabbitMQ y abre automaticamente
todas las terminales necesarias.
