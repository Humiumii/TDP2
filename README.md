## Cómo correr el proyecto

Leer `requirements.txt` e instalar todo lo que sea necesario.

Estando dentro de la carpeta del proyecto, ejecutar en orden:

```bash
docker compose up -d

make run
```

Eso es todo. El sistema levanta RabbitMQ y abre automáticamente todas las terminales necesarias.
